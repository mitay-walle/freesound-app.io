# Freesound App

Локальное веб-приложение для сёрфинга по [freesound.org](https://freesound.org) с расширенным поиском и чёрным списком авторов.

Без зависимостей: нужен только Node.js 20+.

## Запуск

```bash
node server.js
```

Откройте http://127.0.0.1:8765/ в браузере.

Режим без API-ключа, на тестовых данных (для разработки интерфейса):

```bash
node server.js --mock
```

Порт меняется переменной окружения `PORT`, адрес интерфейса — `HOST`.

## Подключение к Freesound

При первом запуске нажмите **Войти** в шапке (или «Настроить доступ» в центре экрана): откроется пошаговая настройка.

1. На https://freesound.org/apiv2/apply создайте ключ API (нужен аккаунт Freesound). В форме «Create new API credentials»:
   **Name** любое, **URL** можно оставить пустым, в **Callback URL** вставьте `http://127.0.0.1:8765/oauth/callback`
   (точный адрес показан в окне настройки, рядом кнопка «скопировать»), **Description** обязательно. Ключ выдаётся сразу.
2. Вставьте **Client ID** и **Client secret / API key** в форму. Это одно и то же значение, что Freesound называет
   «Api key», поэтому отдельного поля для ключа нет. Поля сохраняются автоматически.
3. Нажмите **Сохранить и войти**: во всплывающем окне Freesound подтвердите доступ. Окно закроется само, в шапке появится
   ваш ник. Вход нужен для скачивания оригиналов (wav/flac); поиск и превью работают и без него («Сохранить без входа»).

Если в Callback URL указан `http://freesound.org/home/app_permissions/permission_granted/`, Freesound покажет код
авторизации на своей странице: вставьте его в поле «код авторизации» в настройках. Токен обновляется автоматически, выйти можно из меню под ником.

Лимиты Freesound: 60 запросов в минуту и 2000 в день на аккаунт. Текущее использование видно в плитке «API запросы».

## Возможности

- **Поиск** с операторами Freesound: `-слово` исключает, `"фраза"` ищет точно.
- **Конструктор фильтров** поверх Solr-синтаксиса API с кастомными контролами (двойные min/max слайдеры с логарифмической шкалой, сегментированные переключатели, звёзды рейтинга): теги (все/любой/исключить), категория и подкатегория Broad Sound Taxonomy, формат, каналы, частота, разрядность, размер, длительность, лицензия, рейтинг, число оценок и скачиваний, дата загрузки, автор, пак, геотег, ремиксы, BPM, нота, тональность, loopable, реверберация, громкость и произвольные диапазоны по ~70 аудио-дескрипторам.
- **Экспертный режим**: дополнительный Solr-фильтр, полностью ручной фильтр, сортировка по числовой цели (`pitch:220`), веса полей, показ итогового URL запроса.
- **Похожие звуки** по ID образца в пространствах `laion_clap` и `freesound_classic`.
- **Чёрный список** авторов, тегов, паков и слов: сервер добавляет `-username:(…) -tag:(…) -pack:(…)` в фильтр и `-слово` в запрос каждого поиска, остальное (паки по ID, слова в описаниях, списки без фильтра) скрывается на клиенте. Блокировка в один клик: значок запрета у автора, у тега (при наведении) и у пака, правый клик по карточке открывает меню со всеми вариантами. Импорт/экспорт.
- **Плеер** с волновой формой, перемоткой, повтором, автопереходом к следующему; пробел — пауза, `/` — в строку поиска, Shift+←/→ — предыдущий/следующий.
- **Карточка звука**: спектрограмма, все метаданные, комментарии, дескрипторы анализа.
- **Автор и пак** в модальном окне, поиск только по автору, «ещё из этого пака».
- **Избранное** локально, экспорт JSON, пакетное скачивание превью.
- **Скачивание** превью (mp3/ogg) и оригиналов в папку, журнал загрузок, файл `_attribution.txt` с указанием авторства и лицензии.
- **Сохранённые поиски**, история запросов, состояние поиска в URL.
- **Дизайн**: тёмная плоская тема без скруглений, плитки со статистикой, шрифт Poppins (с системным запасным).

## Где хранятся данные

Всё в папке `data/` рядом с сервером (в `.gitignore`):

- `settings.json` — ключи и настройки;
- `blacklist.json` — чёрный список;
- `favorites.json`, `searches.json`, `downloads.json`;
- `oauth.json` — токены OAuth2 (обновляются автоматически).

Файлы звуков скачиваются в `downloads/` (папку можно сменить в настройках).

## Структура

- `server.js` — HTTP-сервер: статика, прокси `/api/*` к `https://freesound.org/apiv2/*`, локальные маршруты `/local/*`, OAuth2 `/oauth/*` (callback отдаёт страницу, которая сообщает результат окну приложения через postMessage).
- `public/index.html`, `public/style.css`, `public/app.js` — интерфейс; `public/controls.js` — слайдеры, сегментированные переключатели, звёзды.
- `public/fields.js` — таксономия, лицензии, каталог полей для фильтров.
- `mock/sounds.json` — данные для `--mock`.
